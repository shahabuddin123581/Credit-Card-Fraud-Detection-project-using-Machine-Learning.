# Credit-Card-Fraud-Detection-project-using-Machine-Learning.
Credit Card Fraud Detection using Machine Learning on the creditcard.csv dataset. Performed data analysis, correlation heatmap, SMOTE balancing, Random Forest and Logistic Regression modeling, confusion matrix, ROC curve, Precision-Recall curve, cross-validation, and feature importance using Python, Pandas, Seaborn, Matplotlib, and Scikit-learn.
Credit Card Fraud Detection project built using Python and Machine Learning on the creditcard.csv dataset.

What I implemented:
• Data preprocessing and dataset exploration
• Fraud vs Valid transaction analysis
• Correlation matrix and heatmap visualization
• Feature and target separation (X and Y)
• Train-test split using Scikit-learn
• Random Forest Classifier model training
• Logistic Regression model comparison
• SMOTE for handling imbalanced fraud data
• Performance evaluation using Accuracy, Precision, Recall, F1-Score
• ROC Curve and Precision-Recall Curve
• Confusion Matrix visualization
• Cross-validation for model reliability
• Feature importance analysis

Libraries Used:
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Imbalanced-learn

This project helped me understand fraud analytics, imbalanced classification, and real-world machine learning workflows.
